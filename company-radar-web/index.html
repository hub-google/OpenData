CORE LOGIC

異動不是商機，異動只是 Sensor

真正要找的是「這個訊號出現後，公司未來幾個月還可能花什麼錢」。所以系統把訊號分成前段、前中段、後段／風險，而不是看到異動就加分。

目前高價值訊號

  • 巨額標案履約：大型專案已進入執行期，常伴隨設備、人力、分包、保險與週轉需求。
  • 新設分公司：新據點正式落地，比公司搬家更接近展店／擴點需求。
  • 營業項目新增：可能是新事業準備啟動，屬於真正偏前段的訊號。
  • 新設立：法人剛成立，供應商與營運配置可能尚未固定。
  • 增資：不是缺錢，而是資金已到位；後續擴產、擴編與採購值得追。
  • 產業異動：稅籍行業方向變化，可能代表新業務或收入結構改變，需再驗證。

不再誤判的訊號

  • 地址變更：通常是搬完才登記，只能佐證擴張，不能拿來賣搬家與裝潢。
  • 名稱變更：本身幾乎不代表採購需求。
  • 一般公司異動：不知道改了什麼前，不進高優先名單。
  • 減資：較適合風險／授信監控，不是一般銷售商機。

下一層要補的領先訊號

  • 已接：營業項目新增、新設分公司、巨額政府採購履約、台灣就業通徵才佐證。
  • 下一階段：工廠登記／新廠、建照與使用執照、特許業許可。
  • 待專門介接：動產擔保目前是公開查詢網站而非穩定批次 API，需另外做查詢器與節流機制。
  • 不會亂接：一般搬遷、改名、不明變更維持低權重。
