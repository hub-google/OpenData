LIVE DATA PIPELINE

現在不是假資料 Demo

網站讀取 GitHub Actions 每日產生的 JSON。資料管線會下載全國營業中稅籍資料，並查詢經濟部當日公司設立與公司異動 API。

已接入資料

  • 財政部：全國營業（稅籍）登記資料集
  • 經濟部：公司資料設立查詢 API
  • 經濟部：公司資料異動查詢 API
  • 每日 SQLite baseline 與前後快照差分

事件怎麼判定？

  • 新設立：以經濟部當日設立 API 為準
  • 增資／減資：今日與前次快照公開資本額不同
  • 搬遷：公開營業地址與前次快照不同
  • 產業異動：稅籍行業代號／名稱與前次快照不同
  • 其他公司登記異動：官方確認有異動，但目前差分欄位不足以細分

重要限制

  • 第一次執行只建立 baseline；真正的前後差分從下一次成功同步開始。
  • 商機分數是透明規則式分數，不代表成交機率。
  • 資料來自政府公開資料，仍應在正式商務接觸前再次查核。
