## 目前架構

- GitHub Pages：前端定位、附近搜尋、距離排序。
- **不再每 5 分鐘抓全台停車資料，也不讀舊快取。**
- 使用者按「定位並查附近」或「更新車位」時，才依目前座標與搜尋半徑判斷需要查哪些已接縣市。
- 當下直接呼叫地方政府官方停車 API；單一 HTTP / JSON 請求失敗會自動重試最多 3 次，每次都有 10 秒 timeout。
- 縣市交界可同時呼叫多個政府來源，再依座標距離合併排序。
- 若官方 API 連續 3 次失敗，該來源本次直接標示失敗，不拿舊資料冒充即時資料。
- 價格與車位欄位優先採官方直接欄位，不用模糊名稱或自然語言推論補值。
