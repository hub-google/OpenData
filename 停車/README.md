# 停車

政府 Open Data 即時找車位實驗專案。

- [PRD](./PRD.md)
- [全台縣市停車 API 盤點](./全台縣市停車API盤點.md)
- [GitHub Pages](https://hub-google.github.io/OpenData/%E5%81%9C%E8%BB%8A/)

## 目前架構

- GitHub Pages：前端定位、附近搜尋、距離排序。
- **不再每 5 分鐘抓全台停車資料，也不讀舊快取。**
- 使用者按「定位並查附近」或「更新車位」時，才依目前座標與搜尋半徑判斷需要查哪些已接縣市。
- 當下直接呼叫地方政府官方停車 API；單一 HTTP / JSON 請求失敗會自動重試最多 3 次，每次都有 10 秒 timeout。
- 縣市交界可同時呼叫多個政府來源，再依座標距離合併排序。
- 若官方 API 連續 3 次失敗，該來源本次直接標示失敗，不拿舊資料冒充即時資料。
- 價格與車位欄位優先採官方直接欄位，不用模糊名稱或自然語言推論補值。

## 已接前端來源

- 臺北市政府停車 Open Data：靜態停車場 + 即時剩餘車位。
- 新北市政府資料開放平臺：停車場 + 即時剩餘車位。
- 桃園市政府資料開放平臺：路外停車即時資訊。

其他縣市的免費官方來源與欄位實測結果請看「全台縣市停車API盤點.md」；在來源未達到可直接、安全映射前，不硬接進正式頁面。
