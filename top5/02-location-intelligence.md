# 02｜台灣選址與商圈情報

## 為什麼值得做
- 商業價值：94/100
- 估計台灣單一產品年營收：5,000萬～3億元以上
- 可能客戶：連鎖餐飲、藥局、便利商店、健身房、房仲、建商、銀行、保險、加盟總部。
- 解決問題：要判斷一個地方值不值得開店，不能只看人口，還要同時看年齡、所得、房價、競爭店、交通與新建案。

## 需要的資料

### 1. 村里戶數與單一年齡人口
- 官方頁：https://data.gov.tw/dataset/77132
- API 文件：https://www.ris.gov.tw/rs-opendata/api/Main/docs/v1
- API：https://www.ris.gov.tw/rs-opendata/api/v1/datastore/ODRP014/yyymm
- 需要欄位：統計年月、行政區代碼、行政區、村里、戶數、總人口、男女人口、各單一年齡男女。
- 可以衍生：0～6歲、7～12歲、30～39歲、40～49歲、65歲以上等客群人口。

### 2. 村里所得
- 官方頁：https://data.gov.tw/dataset/103066
- 需要欄位：鄉鎮市區、村里、納稅戶數、綜合所得總額、平均數、中位數、第一分位數、第三分位數。
- 注意：這是綜所稅申報資料，不完全等於家庭可支配所得。

### 3. 不動產實價登錄
- 官方頁：https://data.gov.tw/dataset/25119
- 直接下載：https://plvr.land.moi.gov.tw/opendata/lvr_landAcsv.zip
- 需要欄位：交易日期、地址、交易類型、土地面積、建物面積、總價、單價、建物型態、用途、屋齡、樓層、車位。

### 4. 全國稅籍營業資料
- 官方頁：https://data.gov.tw/dataset/9400
- CSV：https://eip.fia.gov.tw/data/BGMOPEN1.csv
- 需要欄位：統編、營業地址、行業代號、名稱、設立日期。
- 用途：知道附近有多少競爭店、哪些產業正在增加。

## 可以算出哪些有價值的指標
- 兒童家庭密度。
- 高齡人口密度。
- 30～45歲消費主力人口。
- 所得中位數。
- 500公尺／1公里生活圈人口。
- 同類店家競爭密度。
- 新店開設速度。
- 房價與租金替代指標。
- 新建案增加速度。
- 綜合展店分數。

## 可以做成什麼產品

### 展店評分
輸入：
- 我要開什麼店。
- 主要客戶幾歲。
- 客單價多少。
- 希望在哪個城市。

系統直接推薦最適合的村里或街區。

### 商圈分析
讓加盟總部或連鎖品牌比較不同據點。

### 房產區域評估
把人口、所得、成交價、新建案與交通結合。

## 商業模式
- 展店系統：每月 5,000～50,000 元。
- 大型企業地理資料服務：每年 50萬～500萬元。
- 單點選址報告：每點 2萬～20萬元。
- 房產估值或區域評分 API：按查詢量收費。

## 最推薦的第一版
先做「台北市展店評分」。

使用者輸入店型與目標客群，系統直接列出台北最值得開店的 20 個村里，並解釋人口、所得、競爭店、房價與交通原因。
