資料來源

本網站從第三方公開的 OpenFun 政府採購公告 API 即時取得資料。該 API 蒐集政府電子採購網公開公告。官方紀錄請以 政府電子採購網 為準。機關年度統計使用 OpenFun /api/unitstat。

API 無 Token 可能有流量限制或延遲；出錯時不會使用模擬資料。公開可讀不等於可無限制商業再利用，正式商用仍須釐清來源授權。

有哪些是真正的功能？

真實資料搜尋、公告詳情與歷史、機關年度統計、廠商公告查詢、依資料可用性計算決標比、CSV／RSS 檔案下載、個人商機匹配、追蹤看板、ICS 日曆、瀏覽器開頁檢查通知、本機文字文件檢核。

哪些尚未完成驗收？

會員與雲端保存、多人協作及 AI 文件解析的後端程式已建立，實際帳戶登入與 AI 服務仍需通過端到端測試；AI 另須配置金鑰才能運作。LINE／Email 背景外送需要獨立且合法授權的發送服務；目前只有伺服器產生的站內通知。全量歷史資料持續回補中，尚未完成所有年度收錄及商業授權確認。
