DATA & TRUST

資料來源與使用說明

清楚說明哪些資料是真實來源、哪些只是本機計算，以及還沒完成的後端功能。

資料來源

本網站從第三方公開的 OpenFun 政府採購公告 API 即時取得資料。該 API 蒐集政府電子採購網公開公告。官方紀錄請以 政府電子採購網 為準。機關年度統計使用 OpenFun /api/unitstat。

API 不需 Token 的呼叫可能有流量限制或資料延遲；錯誤時顯示原因，不使用模擬資料冒充。API 可跨網域呼叫，但**公開可讀不代表可無限制商業再利用**，正式商用前應依官方資料集授權與採購網著作權政策評估。

有哪些是真正的功能？

真實資料搜尋、公告詳情與歷史、機關年度統計、廠商公告查詢、依資料可用性計算決標比、CSV／RSS 檔案下載、個人商機匹配、追蹤看板、ICS 日曆、瀏覽器開頁檢查通知、本機文字文件檢核。

哪些尚未接後端？

多裝置同步、會員登入、雲端儲存、Email／LINE 背景通知、正式 AI 模型解析、批次歷史全量統計，以及更完整來源的商用授權。這些功能不以假按鈕充數，也不收費。
